# 察して。Reboot

「空気を読む」を、場面を観察して直接働きかける遊びへ再設計する Web ゲームプロジェクトです。

旧版 [`a04sb025-ai/sasshite`](https://github.com/a04sb025-ai/sasshite) の単純改修ではありません。得られた知見は参考にしつつ、ゲームの面白さ、操作感、分かりやすさをゼロから検証します。

## 現在のフェーズ

企画フェーズです。本格的なゲーム実装はまだ開始していません。最初にコアゲームループと「究極の 1 ステージ」を人間がレビューし、その承認後に技術検証へ進みます。

- [企画書: コアループ比較と究極の 1 ステージ](docs/concept.md)
- [AI 開発者向け最優先ルール](AGENTS.md)

## 方針

- 文章選択式の常識クイズではなく、画面内の状況へ介入する。
- スマートフォンでの初見理解とゲームフィールを最優先する。
- 大量のステージより、何度も試したくなる 1 ステージを先に作る。
- 技術スタックは、承認されたコア体験に必要な性能と操作から選定する。

企画の判断経緯、旧版の調査制約、専門家レビューは企画書に記録しています。
